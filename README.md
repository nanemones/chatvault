## 30-Second Install (Chrome / Edge / Brave / Arc)

1. Download **`chatvault-v1.0.0.zip`** from the [Latest Release](https://github.com/nanemones/chatvault/releases/latest) and unzip it.
2. Open `chrome://extensions/` (or `edge://extensions/`).
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder.
5. Open any ChatGPT, Claude, Gemini, or NotebookLM chat and click the **ChatVault (CV)** icon!
